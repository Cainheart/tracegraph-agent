# 配置继承与安全设置历史

[English](2026-10-05-cfg-098-inheritance-history.md)

## 决策

新任务按显式请求、持久化会话覆盖、Profile 内项目默认值、当前全局模型/推理与权限默认值解析。省略代表继承；旧完整会话记录保留为显式覆盖。新会话只保存显式传入值。CAS 重置删除选定覆盖，不修改已准入任务。项目默认值不能超过 Host 固定权限上限，不能绕过撤销授权或仅可收紧的项目策略。

Profile 设置历史使用现有规范 Workbench 命令日志。记录安全初始检查点及成功更新/恢复的版本、命令和脱敏设置；历史和命令回执不保存凭据或工具环境/参数明文。恢复创建新版本并校验当前版本；历史中含脱敏字段的设置分组保留当前值。凭据、用户同意和仓库策略不属于设置恢复权限。原私有设置仍是实际配置源，不重写既有历史。未知命令结果保持未知，不自动重新派发。

## 范围与验证

本切片交付全局/项目/会话继承及 Profile 设置历史恢复，贯通认证 Host、类型 SDK、固定 Desktop 桥和 CLI。项目/会话历史恢复、客户端外观继承、所有设置安全空闲自动重启及凭据历史不属于本切片。验证优先级、省略语义、旧记录保留、CAS 冲突、重启持久化、脱敏、撤销/权限上限及已准入模型快照冻结。

## 恢复

增量契约保留旧读取。旧会话选项在内存中成为显式覆盖，下次写入持久化。历史恢复不重放任务、不改变已冻结模型或权限。回滚保留原文件和日志。
