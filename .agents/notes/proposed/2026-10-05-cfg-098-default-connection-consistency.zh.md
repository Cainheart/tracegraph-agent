# Agent Note：默认连接与实际选项一致性

[English](2026-10-05-cfg-098-default-connection-consistency.md)

## 当前差距

已保存服务可按对话选择，但全局默认没有公开选择命令。项目默认值在切换服务后可能保留不兼容的模型或推理强度。完全访问已选、授权待生效或已撤销时，权限按钮却显示工作区访问。部分测试结果缺少中文翻译。

## 已接受决策

新增可选公开字段 `default_revision`，持久版本兼容旧配置并默认为零。非空的默认选择命令绑定规范命令 ID、默认版本和目标连接版本。只可选有凭据的可写已保存连接；环境托管连接保持只读，但不阻止选择普通已保存连接。HTTP、SDK、固定 Desktop 桥和 CLI 共用同一控制器。规范 Journal 的失败和未知回执可按原 ID 只读核对，不自动重发变更。当前任务的配置和凭据租约保持不变。

项目选项在切换服务或模型时归一化关联的模型与推理强度。元数据区分草稿变更、已保存来源和实际生效值。Host 在权限或服务商请求派发前，独立拒绝确切服务及模型不支持的推理强度；不根据模型名称猜测能力，也不静默降低明确选择。

完全访问标签区分已保存选择、授权待应用及已撤销，不能声称已自动退回工作区权限；用户可明确选择其他预设。协议枚举和不可变权限上限保持不变。翻译只覆盖实际结果、凭据和费用标签。

## 验证与恢复

通过真实临时配置、规范 Journal 和受控本机 HTTP 验证 CAS、冲突命令、只读目标、重开持久状态、推理拒绝零派发和任务租约稳定。挂载 UI 负例验证服务/模型/强度联动、真实权限标签及明确默认选择与核对。不用用户 Key 或付费请求。现有冻结安装包证据是本切片之前的历史，安装验收等待父任务之后的构建。

## 延后边界

本切片不实现完整设置继承、网络代理、记忆生命周期或能力推断。响应丢失时保留命令 ID 并核对；当前默认值本身不能证明原命令已完成。
