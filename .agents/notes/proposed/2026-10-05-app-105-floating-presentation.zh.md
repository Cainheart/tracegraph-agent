# 桌面浮动展示

[English](2026-10-05-app-105-floating-presentation.md)

## 决策与当前边界

托盘和原生“窗口”菜单可将已有可信窗口在普通尺寸和较小的浮动展示间切换，并单独选择置顶。只调整同一窗口，不重新加载界面、不创建另一个客户端，也不发出业务命令。当前对话、草稿、未保存文件和订阅保持，仍由共享 Host 管理任务。两个原生菜单入口使用 Main 所有的固定标识，并显示同一个控制器的状态。

## 权限与失败处理

只有 Main 的固定菜单动作调整原生窗口尺寸。保存的位置限制在当前显示器内，关闭与恢复入口保持可访问。展示切换不授予应用控制、不采集截图、不读取凭据、不启停 Host，也不提交任务。置顶默认关闭，显式选择仅作用于当前应用生命周期。独立第二个界面与全局快捷键附加当前应用截图仍待完成，本切片不声称交付。

## 验证与回退

Main 与控制器测试验证只调整一个窗口、不重新加载界面、不派发规范命令、不替换订阅，并覆盖尺寸恢复与独立置顶状态。在 macOS 的实际源码版 Desktop 中，已通过原生“窗口”菜单将临时 Profile 的窗口切为 880×700，再恢复普通 1440×920 尺寸；未发送草稿在切换后仍存在。截图与实际共享 Profile 核对记录保存在[增量报告](../../../docs/validation/app-105/backend-slice.md)。这些源码窗口证据不证明安装包、原生置顶层级、通知送达或 Windows 行为。回退移除两个菜单动作，不改变 Profile、对话或 Ledger。APP-105 整体目标仍未完成。
