# 可恢复的后台连接与完整聊天工作台

## 问题
安装版 Desktop 在外部重启后保留旧认证，设置页把连接失败误报为功能不支持。真实 Web 旅程又复现了地址不变、认证令牌已更换的情况：下一次明确保存文件在受理前被拒绝。各页面输入框不同、模型选择全局共享，原生图标有重复底板与裁切。保留的失败记录区分产品缺陷与验收脚本错误。

## 当前实现
[共享监督器](../../../packages/host/src/local-connection-supervisor.ts)重新绑定后台身份及代际，有界恢复，保留显式停止，不自动执行中断任务。Desktop 激活时检查后台；CLI 共用监督器。用户明确重新启动已退出的应用可修复已停止后台一次；同一 Main 进程中的激活或重新打开窗口保留停止意图。[HTTP 认证](../../../packages/sdk/src/index.ts)在明确的实时写操作前通过一次有时限的共享校验，然后只派发一次。过期的认证响应不能覆盖回放凭据；固定 Main/preload 桥区分明确认证拒绝与派发后结果未知。

[会话控制器](../../../packages/host/src/conversation-control.ts)持久化模型服务与会话下一任务选项，并保留旧凭据引用。模型、凭据版本与权限在受理时冻结。本机完全访问资格通过同意流程保存，与新会话默认工作区权限分离，不能突破管理员上限。删除或清除服务凭据不破坏已受理任务；新任务需要可用凭据。计划模式进入 Runtime 写入限制。逐模型图片输入声明保存在服务配置并在受理时冻结；未声明默认关闭，文本连接测试不冒充图片支持验证。

[文件与反馈](../../../packages/host/src/project-files-feedback.ts)提供有界项目目录、UTF-8 读取、受校验图片预览和带原哈希的条件保存，经过精确审批、工作区协调、持久回执与对账。反馈绑定真实公开回答，仅保存在本机。[编辑器](../../../packages/workbench/src/components/ProjectFiles.tsx)保留未受理意图供明确重试，未知结果先查询；成功保存后的读取失败不会抹去成功回执。[共享工作台](../../../packages/workbench/src/App.tsx)统一输入框，左侧为添加、权限、计划，右侧为模型和提交，并按需展示文件、变更、终端、预览、成果面板。变更卡片要求真实应用回执，预览不计入；历史检查只读。

项目文件上下文是带版本的项目相对路径选择，与用户任务和图片/PDF 暂存分离。Host 受理时重新检查权限、路径和哈希，并冻结有界 UTF-8 快照。Core 只通过可信派发接收快照，写入范围明确且脱敏的 `project_file_context` Artifact，并提供不可信观察及 Manifest 来源。普通对话不支持项目文件选择；明确恢复读取已受理的 Artifact，不重新读取发生变化的工作区文件。客户端提交的内容不能成为可信上下文。

[B Current](../../../docs/brand/current.svg)是唯一生产矢量源。固定 resvg 渲染派生透明标志、单个暖色原生底板、完整 ICNS 及多尺寸 ICO。构建与安装清单分别标识实际交付字节。旧包名、协议标识及原账本保留为兼容技术标识；产品展示名使用 Outlive Agent。

## 不变量与边界
Host 拥有业务状态及唯一 Runtime 写入者。公开回执元数据不包含私有推理、密钥、编辑内容或图片字节。重连、展开详情及历史检查不执行任务。回放不能刷新实时认证或写入。已派发但结果未知的写入先对账，不能自动重复。文件描述符绑定获准 inode，但外部写入者仍可能与最后哈希检查竞争；这不是原子文件系统事务。现有 UTF-8 文件限制为一 MiB。Windows 原生行为与模型服务质量需要各自证据。

## 迁移与回退
旧单服务配置迁移为默认模型连接；旧目录和事件保留。模型更新使用修订与版本化凭据；活跃租约保留受理时版本。替换应用不修改包外 Profile，并保留可恢复旧应用副本。不同实际产品版本不能共享后台；替换前在空闲时明确停止旧后台。崩溃恢复还原事实并把 Run 标记为中断，不重新执行。

## 验证
[本轮报告](../../../docs/validation/current-workbench-recovery/README.md)保留构建、类型、单元、工程及评估日志，认证与文件负例、真实后台进程重启及崩溃和停止测试、独立外部状态检查及 GUI 尝试记录。新增 GUI 范围及最终安装通过后，这对 Note 才迁入 implemented。早期证据仍为历史，不能证明新安装字节。

## 延后发行条件
签名与公证、干净 macOS/Windows 安装及升级、Windows 原生 UI/PTY/图标、非维护者独立验收继续作为发行条件。回环模型夹具不能证明真实付费 Provider 的质量、账户权限或成本。
