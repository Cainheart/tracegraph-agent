# Agent Note：持久任务结果优先于回答草稿

[English](2026-10-05-public-answer-authority.md)

## 问题与当前状态

ChatTurn 当前优先选择最后一条易失 answer_snapshot，完成或失败后仍可能覆盖持久结果。对应 model.decision 已记录、交付审阅与验证继续时，同一候选也可能保留；渐进显示的游标还会跨越终态。已被拒绝或过期的成功口号因此看起来像正式答案。

## 已授权的窄范围

父任务已授权此显示修复。终态和暂停状态仅显示其持久结果/状态投影；运行中的公开回答明确标为尚未核验的草稿，没有正式复制或赞踩入口。对应模型调用已有规范决定、失败或取消，或出现更新的规范模型请求时，隐藏该候选。仅按模型操作身份配对，不比较表面流游标与账本序号。完全没有模型操作证据时，兼容旧服务的公开文字仍可标为草稿显示；私有思考继续排除。

运行转为终态时立即替换草稿，不继续动画播放旧候选。交付审阅只显示真实公开事实，不能推断成功。既有 TraceEvent 投影保留模型调用身份，但不保留任意交付命令数据；对应模型调用已结束，足以在后续审阅开始前隐藏第一次 finish 候选。

独立 UI 审查后，父任务授权窄补充：完成、历史或待审阅投影没有 outcome 时，仅显示中性的回答缺失提示。单独终态事件不能证明生成物或验证结果，保留的回答候选也不能填补此缺口。受控反例覆盖两种语言及没有验证事实的规范完成事件；安装包验收仍单独记录。

## 备选与边界

拒绝以 completed answer_snapshot 回退，因为它易失且早于交付验收；拒绝隐藏全部公开流式文字，因为普通知识问答在运行时仍应可读。不修改 Runtime 验收、模型适配器、SDK 传输或存储历史。组件测试不代表付费模型质量、安装包图形验收或整个路线图完成。

## 迁移与回滚

不改变持久格式或传输协议。保留的旧表面流仍可解析，但不得覆盖终态结果。回退组件会恢复错误的权威顺序，不能视为安全产品回退。

## 验收条件

- [x] 完成答案和失败错误的持久结果优先于冲突的回答快照。
- [x] finish 候选在交付审阅/修复期间消失，不显示正式回答操作。
- [x] 普通公开流式文字保留为未核验草稿，完成后显示持久结果。
- [x] 已挂载界面在运行转终态时立即显示持久结果，即使开启渐进显示。
- [x] 缺失回答在两种语言下均使用中性提示；没有验证证据的规范终态不能推断已验证结果。
- [x] 当前模块与双语验证证据记录本次源码切片的边界。
