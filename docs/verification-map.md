明确边界：“待审批 Patch”可恢复到重新签发的 approval；“待审批 Plan”可恢复到原 revision 等待态。两者都不会自动重跑 Model/Tool，而非待审批 Run 是只读恢复视图。恢复 Artifact 的 8 MiB 是独立内部硬上限，不改变公开 1 MiB Artifact API，也不把内部引用暴露给客户端。租约冲突审计落在 Host structured log，而不是绕过争议中的 lease 向目标 Session Ledger 写入；日志持久保存/轮转不由 G-01 提供。Session event ref 不含 ledger locator，因此一个 Session root 只能与其原始 `dataDir` 配对；多个独立 Ledger 共用同一 Session root 会在启动扫描时 fail-closed。

一致性边界：Runtime 先 append canonical Ledger、再 append Session `event_ref`，两者没有跨文件事务。崩溃窗口内 Ledger 仍是事实源，Session 索引可能缺 ref；G-04 会在恢复特定 Patch Action 时用稳定幂等提案补齐其相关 Event 引用，但没有对所有历史 Event 做通用反向索引扫描。
