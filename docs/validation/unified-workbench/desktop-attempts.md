Failed attempts retain their status, assertions completed, screenshots/bytes and cleanup results. No failed receipt is relabelled passed. Expanded final evidence will be recorded only after all required journeys and resource cleanup pass.

The first frozen installed archive failed before any UI assertion because it contained only the example package manifest, while the installed TestSupport helper required the example source/test template. Its unchanged [failed installed receipt](../unified-local-workbench/evidence/attempts/installed-001-missing-fixture-source/report.json) records zero assertions and successful cleanup. The corrected archive includes the six controlled public template files in the closed checksum inventory. The external harness checks and records the same installed tree's template hashes before starting any resources; it does not substitute source files. Its separate [final installed receipt](../unified-local-workbench/evidence/installed-desktop/report.json) passed all 21 journeys and 134 screenshots with complete cleanup.

The harness can be run externally against a frozen installed archive with `OUTLIVE_REPOSITORY_ROOT=/absolute/installed/tree`. Host, SDK, Test Support, CLI and Electron Main resolve from that installed tree; the installed inventory is not modified to insert QA scripts. Output is a separate validation directory. A source run omits this override. Playwright is supplied from an already installed runtime with `OUTLIVE_PLAYWRIGHT_MODULE`; no dependencies are installed by the harness.
