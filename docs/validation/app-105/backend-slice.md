# APP-105 native background entry: current slice

This evidence describes source-level Main composition and real shared profile persistence on 2026-10-05. It does not claim full APP-105, final installer acceptance or OS notification delivery.

The paired proposed decision is [English](../../../.agents/notes/proposed/2026-10-05-app-105-background-entry.md) / [Chinese](../../../.agents/notes/proposed/2026-10-05-app-105-background-entry.zh.md). Sources are [Main](../../../apps/desktop/src/main.ts), [native projection controller](../../../apps/desktop/src/native-background.ts), [Electron effects](../../../apps/desktop/src/native-background-electron.ts), [preload](../../../apps/desktop/src/preload.cts), [navigation contract](../../../packages/contracts/src/application-runtime.ts) and [shared settings](../../../packages/contracts/src/local-workbench.ts). This slice creates no new Ledger or Runtime: settings use existing Host command receipts/CAS/history and notifications consume canonical event identifiers.

A real Tray is composed with the fixed packaged icon; window close retains Main where Tray creation succeeds. Explicit app quit releases Main effects and detaches; it does not stop the owner. A separate native-confirmed action dispatches canonical `host.stop` once. Main initial-load historical notifications are suppressed. New canonical completion/failure/approval events are deduplicated across owner replacement, preference-gated, and omit task content from OS text. The event listener accepts only read-only Run identifiers. Main loads the window and verifies current profile/Run/project/session/generation before forwarding; Replay cannot emit or use it to execute work.

The optional shared `general.prevent_sleep_during_tasks` flag is absent/false by default, is persisted by ordinary settings CAS/history and applies immediately to Main. `prevent-app-suspension` exists only while an opted-in executing Run exists. Approval waiting/queue/idle, Replay/offline and Main quit release it. A window close alone retains Main. OS lock/lid/manual sleep policy and effects after full Main quit are not promised.

## Later increment: one-window floating presentation

The later [floating decision](../../../.agents/notes/proposed/2026-10-05-app-105-floating-presentation.md) adds two fixed Main actions to the Tray and native Window menu. [WindowPresentation](../../../apps/desktop/src/window-presentation.ts) resizes the existing BrowserWindow, clamps restored bounds to the current display, and retains independent always-on-top state. It does not create another renderer, SDK, owner or task.
